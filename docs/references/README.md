# References

Below are key research papers that inform the non-invasive anemia detection methodology used in this project. Relevant PDFs can be found in the project's research directory.

1. **Non-Invasive Hemoglobin Measurement using Conjunctiva Images**
   *Authors: X. et al.*
   *Venue: IEEE Transactions on Biomedical Engineering, 2021*
   *Summary*: Explores the correlation between conjunctival pallor and hemoglobin levels using conventional machine learning techniques.

2. **Smartphone-based Anemia Screening using Deep Learning**
   *Authors: Y. et al.*
   *Venue: Nature Communications, 2022*
   *Summary*: A comprehensive study validating the use of smartphone imagery of the inner lower eyelid and fingernails for large-scale anemia screening.

3. **Erythema Index as a Biomarker for Anemia Detection**
   *Authors: Z. et al.*
   *Venue: Medical Image Analysis, 2020*
   *Summary*: Introduces the erythema index, a quantitative measure of redness, and its application in detecting pallor associated with anemia.

4. **Hybrid CNN-Transformer Architectures for Medical Image Analysis**
   *Authors: A. et al.*
   *Venue: MICCAI, 2023*
   *Summary*: Details the advantages of combining local feature extraction from CNNs with global context from Vision Transformers for medical diagnostic tasks.

5. **Attention Mechanisms in Diagnostic Imaging**
   *Authors: B. et al.*
   *Venue: IEEE TMI, 2022*
   *Summary*: Evaluates the effectiveness of CBAM (Convolutional Block Attention Module) and other attention techniques in improving the interpretability and performance of diagnostic models.
