🩸 Non-Invasive Anemia Detection Using Fingernail Images

This project focuses on detecting anemia using fingernail images instead of traditional blood tests. It applies computer vision and deep learning techniques to analyze nail features and predict anemia in a non-invasive manner.

📌 Problem Statement

Anemia is commonly diagnosed using blood tests, which can be uncomfortable and require medical facilities. A simple and non-invasive screening method can help in early detection.

💡 Proposed Solution

The system uses fingernail images as input. These images are processed using computer vision techniques, and a deep learning model is trained to classify whether anemia is present, avoiding needle-based testing.

⚙️ System Overview

Fingernail images are collected and preprocessed

Image normalization and feature extraction are performed

A deep learning model is trained for classification

The trained model predicts anemia based on nail features

🛠️ Technologies Used

Programming Language: Python

Deep Learning: CNN, Transformer, Attention mechanisms

Computer Vision: Image preprocessing and analysis

Libraries: OpenCV, NumPy, TensorFlow / PyTorch

✨ Key Features

Non-invasive anemia detection

Fingernail image–based analysis

Deep learning–based classification

Useful for early screening

📂 Dataset

The project uses labeled fingernail images collected for academic and research purposes, including both anemic and non-anemic samples.

📊 Results

The model achieved high accuracy during testing and performed better than basic CNN-only approaches, showing that fingernail-based analysis can be effective for anemia screening.

⚠️ Limitations

Performance depends on image quality and lighting

Not intended to replace clinical diagnosis

Requires validation on larger datasets
